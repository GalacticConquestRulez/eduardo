# Image slots — what to drop in, and where

Every picture on the page is a plain `<img>` pointing at a file in `assets/img/`.
**Swapping in a real photograph is a one-line `src` change per slot.** Keep the
listed aspect ratio and the layout will not move.

## Why the photo slots are vector right now

The stock-photo CDNs (Pexels, Unsplash, Pixabay, Wikimedia) are blocked by the
egress policy of the environment this page was built in, so no photograph could
be downloaded or even verified from here. Rather than hardcode stock URLs that
might 404 in production, the photo slots ship with **original SVG artwork we own
outright** — no licence, no attribution, no expiry — generated by
`tools/gen_art.py` in the logo's own palette. It is a real art-directed system,
not grey boxes, so the page is presentable as-is and improves the moment real
photography lands.

The logo itself is the client's supplied artwork and is used as delivered.

## The film

`assets/video/` holds the licensed footage that runs as an ambient band above
the hero.

| File | Size | Notes |
|---|---|---|
| `grooming-reel.mp4` | 1.9 MB | H.264 High, 1280x732, 12.5s, faststart |
| `grooming-reel.webm` | 1.1 MB | VP9 fallback |
| `reel-poster.jpg` | 33 KB | Frame at 11.4s |

It carries no headline, slate or caption. Licensed footage sets a mood; it is
not presented as the company's own work, and captioning it as a case study
would imply otherwise.

Two details worth keeping:

- Each `<source>` declares the **full** `codecs=` string. A browser with no
  H.264 decoder answers "maybe" to a bare `video/mp4`, picks it, and then fails
  rather than falling through to the VP9 source.
- The audio is stripped. Autoplay only works muted, so the track could never be
  heard without a click, and it is dead weight in the download.

The footage is revealed through the heart from the logo mark and then the mask
is removed outright, so the resting state is unmasked video. The heart is used
rather than the paw because a paw has gaps between the toes and the pad, and
scaling it from the centre would open a hole in the middle of the frame.

Motion that starts on its own must be stoppable, so the band carries a pause
control. Visitors with `prefers-reduced-motion` get the poster, no autoplay and
no aperture.

### Replacing the clip

```bash
ffmpeg -i new-clip.mov -t 12.5 -vf "scale=1280:-2" -an \
  -c:v libx264 -crf 25 -preset slow -profile:v high -pix_fmt yuv420p \
  -movflags +faststart assets/video/grooming-reel.mp4
ffmpeg -i new-clip.mov -t 12.5 -vf "scale=1280:-2" -an \
  -c:v libvpx-vp9 -crf 36 -b:v 0 -row-mt 1 assets/video/grooming-reel.webm
ffmpeg -ss 11.4 -i new-clip.mov -frames:v 1 -vf "scale=1280:-2" -q:v 4 \
  assets/video/reel-poster.jpg
```

Update the `codecs=` string in `index.html` if the H.264 profile changes.

## Swapping in photographs

1. Export each photo at roughly **2× its display size**, cropped to the ratio above.
2. Save as `.jpg` (photos) or `.webp` (smaller, well supported) into `assets/img/`.
3. Change the `src` — and the extension in the filename — in `index.html`.
4. Update the `alt` text to describe that specific photo. Alt text is how the
   page reads to screen readers and to Google.
5. Leave the `width`/`height` attributes set to the real pixel dimensions. They
   reserve the space and stop the page jumping as images load.

Do not remove `loading="lazy"` from below-the-fold images, and keep
`fetchpriority="high"` on the hero.

### Sourcing royalty-free photos

Pexels and Unsplash both licence free for commercial use with no attribution
required. Useful searches: *dog grooming*, *pet groomer*, *dog bath*,
*dog salon*, *groomer scissors*, *dog daycare*. Download the largest size
offered, then crop to the ratios above.

Real photography of your own shop will always outperform stock here —
particularly for the before/after sliders and the facility tiles, which are
specifically about *your* space. Stock is the fallback, not the goal.

## The logo

The supplied badge is in place and drives the whole palette. It arrived as a
cleanly keyed transparent PNG (931×978), which is what these files are cut from.

| File | Size | Where it is used |
|---|---|---|
| `logo.webp` / `logo.png` | 760×798 | Hero panel. WebP is served first; the PNG is a quantised fallback via `<picture>`. |
| `logo-sm.webp` | 380×399 | Footer |
| `logo-mark.svg` | vector | Header lockup, hero trust card, artwork plates |
| `favicon.svg` | vector | Browser tab |
| `apple-touch-icon.png` | 180×180 | iOS home screen |
| `og-card.jpg` | 1200×630 | Link previews |

### Why the header does not use the full badge

The badge is a square stacked lockup. Rendered below about 88px tall — which is
all a normal site header allows — the wordmark, the `USA` line and the tagline
turn to mush. This was checked, not assumed: the badge was rendered at 56, 64,
72, 88 and 110px and only the last two held together.

So the badge is deployed the way a busy square emblem should be:

- **Full badge, large** — hero panel, footer, social card, where the dog, the
  palms and the tagline all still read.
- **Horizontal lockup, small** — the header pairs the vector paw-and-heart mark
  with live HTML text (`Dog Grooming USA` + the tagline). Live text stays crisp
  at any size, is selectable, and is readable by screen readers and Google.

The paw mark is redrawn as vector rather than cropped out of the PNG, because
the crop bleeds in palm fronds and part of a dog paw at every tight bounding
box. The vector version is in `tools/gen_art.py` and doubles as the favicon and
the recurring motif on the artwork plates.

### If the logo is revised again

Replace the source PNG and re-run the two commands in "Regenerating" below.
If the colours change, update the sampled palette at the top of
`tools/gen_art.py` **and** the matching `:root` tokens in
`assets/css/styles.css` — they are deliberately kept in step.

## Regenerating the artwork

```bash
python3 tools/gen_art.py assets/img          # plates, paw mark, favicon
```

Brand colours, the icon set, and the plate composition all live at the top of
that file. Changing `SCHEMES` there restyles every plate at once. The palette
constants are sampled from the logo, so keep them and the CSS `:root` tokens in
agreement.

The raster derivatives (`logo.webp`, `logo.png`, `logo-sm.webp`,
`apple-touch-icon.png`, `og-card.jpg`) were cut from the supplied badge with a
one-off script; re-cut them from the new source if the logo is revised.
